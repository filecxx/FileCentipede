Javascript

Если вы управляете веб-сайтом.

Вставьте этот скрипт на свою веб-страницу или поместите код скрипта на свою веб-страницу, но лучше разместить скрипт на своём сайте на случай, если этот сайт недоступен.

<script1 src="//filecxx.com/script/create_filec_address.js"></script1>
Скачать скрипт

Использование:

Передайте JSON в функцию create_filec_address, поля JSON см. JSON 

create_filec_address({uri:"http://...."});

Sample:

fileu:0eyJ1cmkiOiJodHRwczovL2dpdGh1Yi5jb20vZmlsZWN4eC9GaWxlQ2VudGlwZWRlL3Jhdy9tYWluL3JlbGVhc2UvY2hyb21lLmNyeCJ9

Если вы хотите скрыть свой реальный адрес от пользователей или дать некоторые ограничения на загрузку для пользователей, вам следует использовать в программе инструмент \\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\"создать адрес\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\", он может сгенерировать зашифрованный адрес.

(Javascript не может создать зашифрованный адрес.)

JSON: Добавить задачу

Вы можете использовать JSON как адрес для добавления задачи, но помните: JSON-строка должна быть в одной строке.

Ключ Тип Описание
uri Строка Адрес

HTTP / HTTPS / Stream Необязательно

Ключ Тип Описание
method Строка GET, POST ... You know the thing

page_url Строка URL страницы
user_agent Строка User Agent
cookies Строка Cookies
headers Строка HTTP Headers
content_type Строка Content Type (for HTTP POST)
data Строка HTTP request data
connect_timeout Номер Тайм-аут подключения
max_connections Номер Максимум подключений
max_redirect Номер Максимум перенаправлений
max_retry Номер Максимум попыток
file_name Строка Имя файла
speed_limit_download Номер Ограничение скорости загрузки
auto_rename_file bool Автоматически переименовывать файл
ignore_remote_modified Номер Игнорировать удалённые изменения
ignore_server_busy Номер Игнорировать занятость сервера
